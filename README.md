# 팀 뽑기 (빨강·파랑·노랑·초록)

참가자는 자기 휴대폰으로 접속해서 **부서와 이름으로 로그인**하면 **메인 화면**이 나와요. 거기서 **조식 고르기 · 팀 뽑기**를 눌러 **조식 메뉴를 고르고** **뽑아봐!**를 누르면 4팀 중 하나가 정해져요. **일정표**도 메인 화면에서 볼 수 있어요.

- **참가자 화면:** https://dydrkflqmdl.github.io/team-picker/
- **진행자 화면(현황·명단 관리):** https://dydrkflqmdl.github.io/team-picker/board.html (관리자 비밀번호가 필요해요)

## 규칙

- **명단에 있는 사람만** 로그인할 수 있어요. 이름에 섞인 공백은 무시해요("홍 길동"과 "홍길동"을 같은 사람으로 봐요). 엑셀 등에서 붙여 넣을 때 섞이는 보이지 않는 글자·전각 공백도 지워요.
- 로그인하면 **메인 화면**이 나와요.
  - 아직 팀을 안 뽑은 사람에게는 단추 두 개가 보여요: **조식 고르기 · 팀 뽑기**, **일정표 보기**. (조식만 고른 사람에게는 **팀 뽑기**로 보여요.)
  - 조식도 고르고 팀도 뽑은 사람에게는 뽑기 단추 없이 **일정표**(접힌 채) → **우리 팀 사람들** → **내 팀·조식** 순서로 보여요.
  - 메인의 일정표는 처음에 접혀 있어요. 제목 줄(**펼치기/접기**)을 눌러 펴고 접고, 날짜 머리띠를 눌러 그날만 접을 수 있어요.
  - 조식·팀 화면과 일정표 화면에는 **메인으로 돌아가기**가 있어요. 화면 제목과 같은 줄 오른쪽에 이름, 그 아래에 **로그아웃**이 있어요(메뉴를 저장하거나 팀을 뽑는 동안은 눌러지지 않아요).
- **조식 고르기 · 팀 뽑기**를 누르면 먼저 **조식 메뉴(12월 18일 금요일)** 를 골라요. 우거지 해장국·소고기 미역국·버섯 황태 해장국 중 **하나만** 고를 수 있어요.
  - 메뉴를 눌러서 고르고, 다시 눌러서 빼요. 하나를 고른 채 다른 메뉴를 누르면 "하나만 골라 달라"는 문구가 뜨고 나중에 누른 메뉴는 자동으로 빠져요. 바꾸려면 먼저 고른 메뉴를 한 번 더 눌러 뺀 뒤 다시 골라요.
  - 확정하면 참가자는 **바꿀 수 없어요.** 다른 기기에서 다시 골라도 처음 고른 메뉴가 남아요.
  - 메뉴를 확정해야 팀 뽑기로 넘어가요(메뉴가 없으면 DB도 팀을 뽑아 주지 않아요). 조식만 고르고 나간 사람은 메인 화면의 **팀 뽑기**를 누르면 바로 팀 뽑기 화면이 나와요.
- 한 사람은 **한 번만** 뽑을 수 있어요. 다시 들어오면 메인 화면에 처음 뽑은 팀이 그대로 나와요.
- 팀 배정 방법은 이래요.
  1. 누를 때마다 **아직 안 뽑은 사람 전원을 가장 고르게 나누는 계획**을 새로 세우고, 그 계획에서 내 팀을 줘요. 이미 뽑은 사람은 그대로 둬요.
  2. "고르게"는 팀 인원, 임원, 부서마다, 남녀 인원이 4팀에 최대한 똑같이(차이 1명 이내) 나뉘는 거예요. 팀 인원을 가장 먼저 맞추고, 임원은 2배로 신경 써요.
  3. 고른 계획이 여러 개면 지금까지 뽑은 인원이 적은 팀을 골라요. 계획은 매번 무작위로 세우므로 결과는 랜덤이에요.
  4. 뽑는 도중에도 팀 인원 차이는 최대 3명까지예요.
- 임원은 직급에 대표·이사·고문·상무·전무·사장·회장이 들어가면 자동으로 판단해요.
- 29명 명단으로 400번 시뮬레이션한 결과예요(예전 규칙은 모두 고르게 나뉜 게 7%였어요).
  - 팀 인원 8·7·7·7, 임원 2·2·2·1, 여성 3·2·2·2(8명 팀에 3명)는 400번 모두 지켜졌어요.
  - 부서까지 모두 고르게 나뉜 건 98%였고, 나머지도 한 부서가 한 팀에 1명 더 간 정도였어요.
- ⚠️ **명단에 있는데 안 누르는 사람이 있으면** 계획에 잡아 둔 자리가 비어서 팀 인원이 어긋날 수 있어요. **안 온 사람은 뽑기 전에 진행자 화면에서 지워 주세요.** 이미 어긋났다면, 안 온 사람을 지운 뒤 인원이 많은 팀의 한 명을 **다시 뽑기** 하면 맞춰져요.
- 여러 명이 동시에 눌러도 DB가 한 명씩 차례로 처리해서, 인원 균형이 깨지지 않아요.

## 처음 한 번 설정

1. Supabase 대시보드에서 **SQL Editor**를 열고 [`supabase.sql`](supabase.sql)을 통째로 붙여넣어요.
2. 붙여넣은 내용에서 `'여기를-바꾸세요'`를 **관리자 비밀번호**로 바꾸고 **Run**을 눌러요. **무작위 16자 이상**(영문 대소문자·숫자 섞어서)으로 정하세요. 진행자 화면 주소는 공개라 누구나 비밀번호를 대입해 볼 수 있어요.
   - 비밀번호는 저장소 파일에 적지 말고, 편집기 안에서만 바꾸세요.
   - 나중에 SQL을 다시 Run할 때 `'여기를-바꾸세요'`를 그대로 두면, 기존 비밀번호가 그대로 유지돼요.
   - `supabase.sql`이 바뀌면(기능 추가 등) 통째로 다시 Run하면 돼요. 명단, 뽑은 팀, 고른 메뉴는 그대로 남아요.
   - 화면 파일과 `supabase.sql`이 함께 바뀌었으면 **SQL을 먼저 Run한 뒤** 화면 파일을 올려요. 순서가 바뀌면 그사이 진행자 화면이나 이미 열려 있는 참가자 화면이 잠깐 오류를 낼 수 있어요.
   - **행사 중(뽑기를 하는 동안)에는 SQL과 화면 파일을 바꾸지 마세요.** 꼭 바꿔야 하면 참가자에게 새로고침을 안내해요.
3. 진행자 화면에서 비밀번호를 입력해요. **명단 관리**에 명단을 붙여넣고 **추가**를 눌러요. 두 가지 형식을 쓸 수 있어요.
   - 엑셀에서 **이름·직급·성별·부서** 4칸을 그대로 복사해 붙여넣기 (머리글 줄은 자동으로 건너뛰어요)
   - 한 줄에 **이름, 부서** (직급·성별 없이 빠르게 추가할 때)
   - 칸 수가 맞지 않는 줄(예: 번호 칸이 더 있는 5칸)은 넣지 않고 입력칸에 남겨 둬요. 고쳐서 다시 **추가**를 누르면 돼요.
   - 4칸인데 셋째 칸이 성별(남·여·빈칸)이 아니면 칸 순서가 다른 것으로 보고 넣지 않아요(예: 이름·부서·직급·성별 순서). 엑셀 칸 순서를 이름·직급·성별·부서로 맞춰 주세요.
   - 머리글 줄(이름·부서, 성명·소속 등)과 칸을 감싼 따옴표는 알아서 건너뛰거나 지워요.
   - 명단까지 SQL 한 번에 넣고 싶으면, 로컬의 `roster-setup.sql`(설치 SQL + 명단)을 쓰면 돼요. 이 파일은 저장소에 올라가지 않아요.

## 행사 중에

- **진행자 화면:** 5초마다 저절로 새로고침돼요. 방금 뽑힌 사람은 잠깐 반짝여요. 프로젝터에 띄워두면 좋아요. 글자가 작으면 브라우저 확대(Ctrl 또는 ⌘ 와 +)를 쓰세요.
- **명단 관리에서 사람 찾기:** 진행자 화면 맨 아래 **명단 관리**를 열면 제목 옆에 총인원이 나와요.
  - **분류 단추:** 부서·성별·구분(임원/직원)·팀·조식마다 인원수가 적힌 단추가 있어요. 누르면 표에 그 사람들만 보이고, 한 번 더 누르면 풀려요. 여러 분류를 함께 고를 수 있어요(예: 기술부 + 조식 안 고름).
  - **찾기 칸:** 이름·부서·직급으로 찾아요. 띄어쓰기는 무시해요.
  - **정렬:** 표 머리글(부서·이름·직급·성별·팀·조식)을 누르면 그 칸 순서로 줄을 세워요. 한 번 더 누르면 거꾸로예요. 직급은 높은 순이에요.
  - **엑셀 파일로 받기:** 지금 표에 보이는 사람들을 엑셀에서 열리는 파일(CSV)로 내려받아요. 예: 조식 메뉴 하나를 누른 뒤 받으면 그 메뉴를 고른 사람 명단이 돼요. 받은 파일에는 실명이 들어 있으니 저장소에 올리지 마세요.
  - 분류·찾기·정렬은 보는 방법만 바꿔요. 명단 자체는 바뀌지 않고, 화면을 새로고침하면 처음으로 돌아가요.
- **명단에 없다고 나오는 사람:** 진행자 화면의 명단 관리에서 바로 추가하면 돼요(표 아래 **명단 추가**).
- **이름·부서·직급·성별이 틀린 사람:** 명단 표에서 **수정**을 누르면 그 줄이 입력칸으로 바뀌어요. 고친 뒤 **저장**(또는 Enter)을 누르면 돼요. Esc는 취소예요.
  - 이미 뽑은 사람을 고쳐도 팀은 그대로예요.
  - 같은 부서에 같은 이름이 이미 있으면 저장되지 않아요.
- **잘못 뽑힌 사람:** 명단 표에서 **다시 뽑기**를 누르면, 그 사람이 **뽑아봐!**를 다시 누를 수 있어요. 한 사람 **다시 뽑기**는 팀만 지우고 조식 메뉴는 그대로 둬요. 모두 뽑은 뒤에 한 사람만 다시 뽑으면, 인원을 맞추려고 대개 같은 팀이 다시 나와요.
- **처음부터 다시 하기:** **전체 다시 뽑기**를 누르면 모든 사람의 팀과 조식 메뉴가 함께 지워져요.
  - **전체 다시 뽑기**와 **명단 전체 삭제**는 실수로 누르지 않게, 누르면 "초기화"·"삭제"를 직접 적어야 실행돼요.
  - 실행하기 직전에 그때의 명단 전체(팀·조식·객실·자유시간 포함)를 `워크숍_백업_…csv` 파일로 내려받아 둬요. 그래도 잘못 지웠다면 아래 **실수로 지웠을 때**를 보세요.
- **휴대폰으로 명단 표를 볼 때:** 표가 화면보다 넓으면 옆으로 밀어 봐요. 수정·다시 뽑기·삭제 칸은 오른쪽에 붙어 있어요.
- **진행자 두 명이 동시에 쓸 때:** 같은 사람을 둘이 고치면 나중에 저장한 쪽이 남아요. 일정표도 마찬가지예요. 한 사람이 고치는 동안 다른 사람은 보기만 하세요.
- **진행자가 팀이나 메뉴를 지운 뒤:** 참가자가 열어 둔 화면은 다른 앱에 다녀오거나 새로고침하면 바뀌어요. 예전 화면에서 그대로 **뽑아봐!**를 눌러도 메뉴가 없으면 팀이 뽑히지 않고 메뉴 고르기로 돌아가요.
- **조식 메뉴 집계:** 진행자 화면의 **12월 18일 금요일 조식** 칸에 메뉴마다 인원과 고른 사람 이름이 나오고, 아직 안 고른 사람도 따로 나와요.
- **메뉴를 잘못 고른 사람:** 참가자는 못 바꾸지만 진행자는 바꿀 수 있어요. 명단 표에서 **수정**을 누르고 조식 칸을 바꾼 뒤 **저장**하면 돼요. `-`로 두고 저장하면 그 사람이 메뉴를 다시 고를 수 있어요.

## 일정표

진행자 화면의 **일정표** 칸에 적은 글이 참가자 화면에 그대로 나와요(메인 화면의 **일정표 보기**, 다 뽑은 사람은 메인 화면에 바로).

- **적는 법:** **일정 고치기**를 눌러 글로 적어요. 날짜는 한 줄에 따로 적고, 일정은 `10:00 도착`이나 `14:00~16:00 팀 게임`처럼 시간으로 시작하는 한 줄로 적어요. **예시 넣기**를 누르면 고쳐 쓸 수 있는 예시가 들어가요.
  - 날짜 줄을 `Day 1 · 12/17(목) — 화합과 소통`처럼 적으면 꼬리표(Day 1)·날짜·주제로 나눠 보여줘요.
  - 내용에 든 낱말(식사·강의·특강·레크리에이션·이동·출발·자유 시간·사진 등)에 맞춰 그림 표시가 붙고, 강의·세션은 굵게 나와요.
  - `오프닝 : 대표 인사, 일정 안내`처럼 쌍점(앞뒤를 띄운 `:`) 뒤에 적은 설명은 작은 글로 아래에 나와요.
- 저장하면 바로 바뀌어요. 참가자가 열어 둔 화면은 다른 앱에 다녀오거나 새로고침하면 새 일정으로 바뀌어요.
- 적어 둔 일정이 없으면 참가자 화면에는 "아직 일정표가 준비되지 않았어요."라고 나와요.

## 준비해 둔 기능 (시험용: 객실표·자유시간)

필요할지 몰라서 만들어만 둔 기능이에요. **진행자 화면에서만 보이고, 참가자 화면에는 나오지 않아요.** 진행자 화면의 **준비해 둔 기능 (시험용)** 아래 접힌 칸 두 개에 있어요.

- **객실표:** 방은 남자 1~5호, 여자 1~2호로 7개예요.
  - **자동으로 나누기**는 성별마다 방 인원이 최대한 같게(차이 1명 이내) 나눠요. 기준은 직급이 비슷한 사람끼리, 같은 부서끼리, 같은 팀끼리, 무작위 중에서 골라요.
  - 성별이 없는 사람은 자동으로 못 나눠요. **직접 옮기기**를 켜면 이름 옆에 방을 고르는 칸이 나와요.
  - 나눈 뒤에 명단에 추가한 사람은 **방 없는 사람만 넣기**를 누르면 인원이 적은 방에 들어가요.
- **저녁 식사 뒤 자유시간:** 스키와 사우나 중 누가 무엇을 하는지 적어 두는 칸이에요. **직접 고치기**를 켜고 진행자가 이름 옆 칸에서 골라 넣어요. 참가자가 직접 고르는 화면은 없어요.
- **전체 다시 뽑기**는 객실과 자유시간을 지우지 않아요. 각 칸의 **객실 모두 비우기**, **고른 것 모두 지우기**를 쓰세요.

## 행사 전 점검

- [ ] **주간 점검이 잘 돌고 있는지** 저장소 **Actions** 탭 → **주간 점검**에서 최근 실행이 초록색인지 봐요. 월·목 새벽에 Supabase에 요청을 보내 일시정지(1주일 동안 안 쓰면 멈춤)를 막아요. 응답이 이상하면 저장소에 이슈가 열려요.
- [ ] **관리자 비밀번호**가 무작위 16자 이상인지 확인해요. 짧으면 SQL Editor에서 바꿔요(위 **처음 한 번 설정** 2번).
- [ ] **행사장 와이파이와 사내망**에서 휴대폰으로 참가자 화면을 열어 로그인까지 해 봐요. 화면에 "필요한 파일을 받지 못했어요"가 나오면 그 망이 `cdn.jsdelivr.net`이나 `*.supabase.co`를 막는 거예요(LTE로 쓰게 안내).
- [ ] **명단 확정:** 안 오는 사람은 뽑기 전에 지워요(팀 인원이 어긋나지 않게). 임원 직급·성별이 비어 있지 않은지 분류 단추로 봐요.
- [ ] **시험으로 뽑은 기록 정리:** 시험 삼아 뽑았으면 **전체 다시 뽑기**로 지워요. 객실·자유시간은 그대로 남으니 따로 비워요.
- [ ] **일정표·조식 메뉴**를 마지막으로 확인해요. 그림 파일(`shake.jpg`, `ball_*.jpg`, `menu_*.jpg`)은 행사 전에 확정하고 행사 중에는 바꾸지 않아요.
- [ ] **백업:** 진행자 화면 명단 관리에서 **보이는 명단을 엑셀 파일로 받기**(조건 없이)를 눌러 받고, 일정표 글도 복사해 회사 드라이브 등 비공개 위치에 둬요. 뽑기가 끝난 직후에도 한 번 더 받아요.
- [ ] **행사 뒤:** 프로젝터·공용 PC에서는 진행자 화면 맨 아래 **이 기기에서 비밀번호 지우기**를 눌러요(비밀번호가 그 브라우저에 남아 있어요).

## 실수로 지웠을 때(되살리기)

DB가 명단의 줄이 바뀌거나 지워질 때마다 예전 값을 `people_log` 표에 남겨요(참가자·진행자 화면은 이 표를 못 읽어요).

- **명단 전체 삭제를 잘못 눌렀을 때:** Supabase 대시보드 → **SQL Editor**에서 아래를 Run하면 지운 사람들이 팀·조식까지 그대로 돌아와요. 지운 시각 이후에 지워진 줄만 되살리도록 시각을 고쳐 쓰세요.

  ```sql
  insert into people (id, dept, name, title, gender, team, picked_at, menu, room, activity) overriding system value
  select x.id, x.dept, x.name, x.title, x.gender, x.team, x.picked_at, x.menu, x.room, x.activity
  from people_log l, jsonb_populate_record(null::people, l.old) x
  where l.op = 'DELETE' and l.at > now() - interval '30 minutes'   -- 최근 30분 안에 지운 줄
  on conflict do nothing;
  ```

- **전체 다시 뽑기를 잘못 눌렀을 때:** 바뀌기 전 값이 `op = 'UPDATE'`로 남아 있어요. 진행자 화면이 자동으로 받아 둔 `워크숍_백업_전체다시뽑기전_…csv`를 보고, 명단 표의 **수정**으로 조식을 되돌리는 편이 간단해요(팀은 다시 뽑아도 고르게 나뉘어요).
- 기록은 쌓이기만 해요. 행사가 끝나고 필요 없으면 SQL Editor에서 `truncate people_log;`로 비워요.

## 알아둘 점

- 참가자 화면에는 비밀번호가 없어요. **다른 사람의 부서와 이름을 아는 사람은 그 사람 대신 메뉴를 고르거나 팀을 뽑을 수 있어요.** 워크숍용으로 일부러 단순하게 만들었어요.
- 일정표는 명단에 있는 사람으로 로그인해야 보여요(다른 사람의 부서와 이름을 아는 사람도 볼 수 있어요). 외부에 알리면 안 되는 내용은 적지 마세요.
- 팀을 뽑은 사람은 **같은 팀 사람들의 이름·직급·부서**를 볼 수 있어요(그 팀 사람의 부서와 이름을 아는 사람도 볼 수 있어요). 전체 명단은 진행자 화면에서만 볼 수 있어요. 명단 파일은 이 공개 저장소에 올리지 마세요(`roster*` 파일은 `.gitignore`에 들어 있어요).
- 휴대폰은 받은 파일을 10분쯤 기억해요. 그림 파일(`shake.jpg`, `ball_*.jpg`, `menu_*.jpg`)처럼 주소에 `?v=`가 없는 파일을 바꾸면, 그동안은 예전 것이 보일 수 있어요. 꼭 바꿔야 하면 파일 이름을 바꿔 올려요.
- Supabase 무료 프로젝트는 1주일 동안 쓰지 않으면 일시정지돼요. **주간 점검**(`.github/workflows/weekly.yml`)이 GitHub 서버에서 월·목 새벽 3시 17분에 DB에 요청을 보내 막아요(PC가 꺼져 있어도 돼요). 그래도 멈추면 대시보드에서 **Restore**를 누르면 다시 쓸 수 있어요(몇 분 걸려요).
- 공개 저장소의 예약 실행은 저장소에 **60일 동안 변화가 없으면 GitHub이 꺼요.** 행사 뒤에도 계속 쓰려면 가끔 Actions 탭에서 켜져 있는지 봐요.
- 참가자 화면은 비밀번호가 없어서, 부서 목록을 보고 흔한 이름을 대입해 맞히면 그 사람의 팀 사람들 이름까지 볼 수 있어요. 더 막아야 하면 현장에서만 알려 주는 **참가 코드**를 추가하는 방법이 있어요(참가자가 코드를 한 번 더 넣어야 해요).
