# 팀 뽑기 (빨강·파랑·노랑·초록)

참가자는 자기 휴대폰으로 접속해서 **부서와 이름으로 로그인**한 뒤 **랜덤**을 누르면 돼요. 그러면 4팀 중 하나가 정해져요.

- **참가자 화면:** https://dydrkflqmdl.github.io/team-picker/
- **진행자 화면(현황·명단 관리):** https://dydrkflqmdl.github.io/team-picker/board.html (관리자 비밀번호가 필요해요)

## 규칙

- **명단에 있는 사람만** 로그인할 수 있어요. 이름에 섞인 공백은 무시해요("홍 길동"과 "홍길동"을 같은 사람으로 봐요).
- 한 사람은 **한 번만** 뽑을 수 있어요. 다시 들어와도 처음 뽑은 팀이 그대로 나와요.
- 팀 배정 순서는 이래요.
  1. 지금 **인원이 가장 적은 팀들** 중에서만 골라요. 그래서 팀 인원 차이는 항상 최대 1명이에요.
  2. 그중 **내 그룹이 이미 많이 들어간 팀을 피해요.** 그룹은 임원 여부·부서·성별 세 가지예요. 드문 그룹일수록(임원, 작은 부서) 더 강하게 피하고, 임원은 2배로 신경 써요.
  3. 그래도 같으면 랜덤으로 정해요.
- 임원은 직급에 대표·이사·고문·상무·전무·사장·회장이 들어가면 자동으로 판단해요.
- 29명 명단으로 300번 시뮬레이션한 결과예요.
  - 팀 인원은 항상 8·7·7·7이었어요.
  - 임원은 92%가 2·2·2·1로 나뉘었고, 3명 이상 한 팀에 몰린 적은 없었어요.
  - 여성은 77%가 고르게 나뉘었어요.
- 여러 명이 동시에 눌러도 DB가 한 명씩 차례로 처리해서, 인원 균형이 깨지지 않아요.

## 처음 한 번 설정

1. Supabase 대시보드에서 **SQL Editor**를 열고 [`supabase.sql`](supabase.sql)을 통째로 붙여넣어요.
2. 붙여넣은 내용에서 `'여기를-바꾸세요'`를 **관리자 비밀번호**로 바꾸고 **Run**을 눌러요.
   - 비밀번호는 저장소 파일에 적지 말고, 편집기 안에서만 바꾸세요.
   - 나중에 SQL을 다시 Run할 때 `'여기를-바꾸세요'`를 그대로 두면, 기존 비밀번호가 그대로 유지돼요.
3. 진행자 화면에서 비밀번호를 입력해요. **명단 관리**에 명단을 붙여넣고 **추가**를 눌러요. 두 가지 형식을 쓸 수 있어요.
   - 엑셀에서 **이름·직급·성별·부서** 4칸을 그대로 복사해 붙여넣기 (머리글 줄은 자동으로 건너뛰어요)
   - 한 줄에 **이름, 부서** (직급·성별 없이 빠르게 추가할 때)
   - 명단까지 SQL 한 번에 넣고 싶으면, 로컬의 `roster-setup.sql`(설치 SQL + 명단)을 쓰면 돼요. 이 파일은 저장소에 올라가지 않아요.

## 행사 중에

- **진행자 화면:** 5초마다 저절로 새로고침돼요. 방금 뽑힌 사람은 잠깐 반짝여요. 프로젝터에 띄워두면 좋아요.
- **명단에 없다고 나오는 사람:** 진행자 화면의 명단 관리에서 바로 추가하면 돼요.
- **잘못 뽑힌 사람:** 명단 표에서 **다시 뽑기**를 누르면, 그 사람이 다시 랜덤을 누를 수 있어요.

## 알아둘 점

- 참가자 화면에는 비밀번호가 없어요. **다른 사람의 부서와 이름을 아는 사람은 그 사람 대신 뽑을 수 있어요.** 워크숍용으로 일부러 단순하게 만들었어요.
- 명단(이름)은 진행자 화면에서만 볼 수 있어요. 명단 파일은 이 공개 저장소에 올리지 마세요(`roster*` 파일은 `.gitignore`에 들어 있어요).
- Supabase 무료 프로젝트는 1주일 동안 쓰지 않으면 일시정지돼요. 그러면 대시보드에서 **Restore**를 누르면 다시 쓸 수 있어요.
