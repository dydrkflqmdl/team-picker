# 팀 뽑기 (빨강·파랑·노랑·초록)

참가자는 자기 휴대폰으로 접속해서 **부서와 이름으로 로그인**한 뒤, **조식 메뉴를 고르고** **뽑아봐!**를 누르면 돼요. 그러면 4팀 중 하나가 정해져요.

- **참가자 화면:** https://dydrkflqmdl.github.io/team-picker/
- **진행자 화면(현황·명단 관리):** https://dydrkflqmdl.github.io/team-picker/board.html (관리자 비밀번호가 필요해요)

## 규칙

- **명단에 있는 사람만** 로그인할 수 있어요. 이름에 섞인 공백은 무시해요("홍 길동"과 "홍길동"을 같은 사람으로 봐요).
- 로그인하면 먼저 **조식 메뉴(12월 18일 금요일)** 를 골라요. 우거지 해장국·소고기 미역국·버섯 황태 해장국 중 **하나만** 고를 수 있어요.
  - 메뉴를 눌러서 고르고, 다시 눌러서 빼요. 하나를 고른 채 다른 메뉴를 누르면 "하나만 골라 달라"는 문구가 뜨고 나중에 누른 메뉴는 자동으로 빠져요. 바꾸려면 먼저 고른 메뉴를 한 번 더 눌러 뺀 뒤 다시 골라요.
  - 확정하면 참가자는 **바꿀 수 없어요.** 다른 기기에서 다시 골라도 처음 고른 메뉴가 남아요.
  - 메뉴를 확정해야 팀 뽑기로 넘어가요(메뉴가 없으면 DB도 팀을 뽑아 주지 않아요). 이미 고른 사람은 다시 들어오면 바로 팀 뽑기 화면이 나와요.
- 한 사람은 **한 번만** 뽑을 수 있어요. 다시 들어와도 처음 뽑은 팀이 그대로 나와요.
- 팀 배정 방법은 이래요.
  1. 누를 때마다 **아직 안 뽑은 사람 전원을 가장 고르게 나누는 계획**을 새로 세우고, 그 계획에서 내 팀을 줘요. 이미 뽑은 사람은 그대로 둬요.
  2. "고르게"는 팀 인원, 임원, 부서마다, 남녀 인원이 4팀에 최대한 똑같이(차이 1명 이내) 나뉘는 거예요. 팀 인원을 가장 먼저 맞추고, 임원은 2배로 신경 써요.
  3. 고른 계획이 여러 개면 지금까지 뽑은 인원이 적은 팀을 골라요. 계획은 매번 무작위로 세우므로 결과는 랜덤이에요.
  4. 뽑는 도중에도 팀 인원 차이는 최대 3명까지예요.
- 임원은 직급에 대표·이사·고문·상무·전무·사장·회장이 들어가면 자동으로 판단해요.
- 29명 명단으로 400번 시뮬레이션한 결과예요(예전 규칙은 모두 고르게 나뉜 게 7%였어요).
  - 팀 인원 8·7·7·7, 임원 2·2·2·1, 여성 3·2·2·2(8명 팀에 3명)는 400번 모두 지켜졌어요.
  - 부서까지 모두 고르게 나뉜 건 98%였고, 나머지도 한 부서가 한 팀에 1명 더 간 정도였어요.
- ⚠️ **명단에 있는데 안 누르는 사람이 있으면** 계획에 잡아 둔 자리가 비어서 팀 인원이 어긋날 수 있어요. **안 온 사람은 뽑기 전에 진행자 화면에서 지워 주세요.** 이미 어긋났다면, 안 온 사람을 지운 뒤 인원이 많은 팀의 한 명을 **다시 뽑기** 하면 맞춰져요.
- 여러 명이 동시에 눌러도 DB가 한 명씩 차례로 처리해서, 인원 균형이 깨지지 않아요.

## 처음 한 번 설정

1. Supabase 대시보드에서 **SQL Editor**를 열고 [`supabase.sql`](supabase.sql)을 통째로 붙여넣어요.
2. 붙여넣은 내용에서 `'여기를-바꾸세요'`를 **관리자 비밀번호**로 바꾸고 **Run**을 눌러요. 추측하기 어려운 12자 이상으로 정하세요.
   - 비밀번호는 저장소 파일에 적지 말고, 편집기 안에서만 바꾸세요.
   - 나중에 SQL을 다시 Run할 때 `'여기를-바꾸세요'`를 그대로 두면, 기존 비밀번호가 그대로 유지돼요.
   - `supabase.sql`이 바뀌면(기능 추가 등) 통째로 다시 Run하면 돼요. 명단, 뽑은 팀, 고른 메뉴는 그대로 남아요.
3. 진행자 화면에서 비밀번호를 입력해요. **명단 관리**에 명단을 붙여넣고 **추가**를 눌러요. 두 가지 형식을 쓸 수 있어요.
   - 엑셀에서 **이름·직급·성별·부서** 4칸을 그대로 복사해 붙여넣기 (머리글 줄은 자동으로 건너뛰어요)
   - 한 줄에 **이름, 부서** (직급·성별 없이 빠르게 추가할 때)
   - 칸 수가 맞지 않는 줄(예: 번호 칸이 더 있는 5칸)은 넣지 않고 입력칸에 남겨 둬요. 고쳐서 다시 **추가**를 누르면 돼요.
   - 명단까지 SQL 한 번에 넣고 싶으면, 로컬의 `roster-setup.sql`(설치 SQL + 명단)을 쓰면 돼요. 이 파일은 저장소에 올라가지 않아요.

## 행사 중에

- **진행자 화면:** 5초마다 저절로 새로고침돼요. 방금 뽑힌 사람은 잠깐 반짝여요. 프로젝터에 띄워두면 좋아요. 글자가 작으면 브라우저 확대(Ctrl 또는 ⌘ 와 +)를 쓰세요.
- **명단에 없다고 나오는 사람:** 진행자 화면의 명단 관리에서 바로 추가하면 돼요.
- **이름·부서·직급·성별이 틀린 사람:** 명단 표에서 **수정**을 누르면 그 줄이 입력칸으로 바뀌어요. 고친 뒤 **저장**(또는 Enter)을 누르면 돼요. Esc는 취소예요.
  - 이미 뽑은 사람을 고쳐도 팀은 그대로예요.
  - 같은 부서에 같은 이름이 이미 있으면 저장되지 않아요.
- **잘못 뽑힌 사람:** 명단 표에서 **다시 뽑기**를 누르면, 그 사람이 **뽑아봐!**를 다시 누를 수 있어요. 한 사람 **다시 뽑기**는 팀만 지우고 조식 메뉴는 그대로 둬요. 모두 뽑은 뒤에 한 사람만 다시 뽑으면, 인원을 맞추려고 대개 같은 팀이 다시 나와요.
- **처음부터 다시 하기:** **전체 다시 뽑기**를 누르면 모든 사람의 팀과 조식 메뉴가 함께 지워져요. 되돌릴 수 없어요.
- **진행자가 팀이나 메뉴를 지운 뒤:** 참가자가 열어 둔 화면은 다른 앱에 다녀오거나 새로고침하면 바뀌어요. 예전 화면에서 그대로 **뽑아봐!**를 눌러도 메뉴가 없으면 팀이 뽑히지 않고 메뉴 고르기로 돌아가요.
- **조식 메뉴 집계:** 진행자 화면의 **12월 18일 금요일 조식** 칸에 메뉴마다 인원과 고른 사람 이름이 나오고, 아직 안 고른 사람도 따로 나와요.
- **메뉴를 잘못 고른 사람:** 참가자는 못 바꾸지만 진행자는 바꿀 수 있어요. 명단 표에서 **수정**을 누르고 조식 칸을 바꾼 뒤 **저장**하면 돼요. `-`로 두고 저장하면 그 사람이 메뉴를 다시 고를 수 있어요.

## 알아둘 점

- 참가자 화면에는 비밀번호가 없어요. **다른 사람의 부서와 이름을 아는 사람은 그 사람 대신 메뉴를 고르거나 팀을 뽑을 수 있어요.** 워크숍용으로 일부러 단순하게 만들었어요.
- 명단(이름)은 진행자 화면에서만 볼 수 있어요. 명단 파일은 이 공개 저장소에 올리지 마세요(`roster*` 파일은 `.gitignore`에 들어 있어요).
- 휴대폰은 받은 파일을 10분쯤 기억해요. `style.css`나 그림처럼 주소에 `?v=`가 없는 파일을 바꾸면, 그동안은 예전 것이 보일 수 있어요.
- Supabase 무료 프로젝트는 1주일 동안 쓰지 않으면 일시정지돼요. 그러면 대시보드에서 **Restore**를 누르면 다시 쓸 수 있어요.
